# Riva website (static, RTL Persian)

Structure:
- index.html, products.html
- css/style.css, js/products.js (edit PRODUCTS list to manage products)
- assets/img/ (images; design-*-reference.png are only mockups, safe to delete)

Publish on GitHub Pages:
1. Create repo (e.g. `riva` or `USERNAME.github.io`) and upload these files at the repo root.
2. Settings → Pages → Source: "Deploy from a branch" → main / (root) → Save.
3. Site URL: https://USERNAME.github.io/ (or /riva/). All paths are relative, so both work.
